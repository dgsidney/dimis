Perguntas Frequentes

O dimis é realmente gratuito? +

Sim! O dimis é 100% gratuito para download e uso pessoal ou comercial. Não há período de testes, assinaturas ou recursos bloqueados. Quem quiser ajudar na manutenção do projeto pode contribuir voluntariamente com qualquer valor via Pix.

Meus dados, senhas e conversas ficam seguros? +

Absolutamente. O dimis não tem servidores intermediários para ler ou armazenar suas mensagens. Ele é um aplicativo cliente que carrega diretamente o WhatsApp Web oficial da Meta em contêineres locais isolados no seu próprio Windows. Todas as suas conversas continuam criptografadas de ponta a ponta pelo WhatsApp.

Quantas contas de WhatsApp posso cadastrar? +

Não há limites impostos pelo aplicativo. Você pode conectar quantos números de WhatsApp a memória RAM do seu computador aguentar com tranquilidade. Como o dimis é ultra leve, ele consome uma fração do que navegadores com 20 abas abertas exigiriam.

Há risco de meu número ser bloqueado ou banido? +

Não. O dimis não realiza disparos em massa automáticos, não usa robôs e não modifica a API do WhatsApp. Ele atua exatamente como um navegador oficial (Chrome) abrindo o WhatsApp Web legítimo. Para a Meta, você está apenas acessando o WhatsApp Web normalmente.

Preciso ler o QR Code toda vez que abrir o dimis? +

Não! Cada conta adicionada tem uma partição persistente exclusiva. Uma vez conectado, você pode fechar o app ou reiniciar o computador e suas contas continuarão prontas para uso imediato.

Por que o Windows Defender ou o navegador exibiu um aviso ao baixar? +

Isso é um procedimento padrão do Windows SmartScreen e dos navegadores para qualquer aplicativo executável (.exe) novo e independente que ainda não possui um certificado corporativo pago da Microsoft. O dimis é 100% limpo, sem propagandas, sem arquivos ocultos e roda localmente. Para instalar com tranquilidade, basta clicar em "Mais informações" e depois em "Executar assim mesmo".
